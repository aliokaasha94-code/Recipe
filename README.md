# كافيه ومحمصة عماد أفندي | منظومة البار الذكي وكتيب التشغيل الرقمي (Smart Bar SOP) ☕👑

> **"قهوتك على مزاجك"** — نظام التشغيل القياسي وإدارة محطات العمل الثلاث بكافيه ومحمصة عماد أفندي، تحت إشراف **مجموعة العطيان** (Al-Attiyan Group).

---

## 🚀 نبذة عن النظام
تم بناء هذا النظام ليحل مشكلة **دوران العمالة (Staff Turnover)** والاجتهادات الفردية وتفاوت الجودة، بدلاً من الأوراق والاستيكرات التقليدية التي تتلف وتتقشر ولا يمكن تعديلها.

النظام موزع على **3 محطات تشغيل أساسية (Operational Stations)**، لكل محطة **QR Code مستقل وثابت لا يتغير أبداً**، وعند مسحه بكاميرا الهاتف يفتح صفحة الويب المخصصة للمحطة بدقة 100%.

---

## 📍 محطات العمل الثلاث (The 3 Stations)

### 1️⃣ محطة مكنة الإسبريسو والفلتر (`/stations/espresso/`)
* **مشروبات ساخنة:** إسبريسو، كورتادو، فلات وايت، كابتشينو، لاتيه، سبانيش، بيستاشيو، وايت موكا، كراميل ميكاتو، موكا، أمريكانو، كون بانا، أفوجادو، بونبون.
* **مشروبات باردة:** آيس لاتيه، آيس سبانيش، آيس بيستاشيو، آيس وايت موكا، آيس كراميل، آيس موكا، آيس أمريكانو.
* **القهوة المقطرة (Manual Brew):** V60، كيمكس (Chemex)، وكولد برو (Cold Brew).
* **المميزات:** تبديل تلقائي فوري بين مقاسات الأكواب (8oz / 12oz / 16oz)، وعيادة معالجة الاستخلاص السريع والبطيء دون إهدار البن.

### 2️⃣ محطة التركي والتراثي والساخن (`/stations/traditional/`)
* **القهوة التركية الكلاسيكية:** فاتح، وسط، غامق (سادة ومحوج بالهيل والمستكة - سنجل ودبل).
* **القهوة الفرنساوي الفاخرة بالحليب:** كلاسيك، بندق، كراميل، شيكولاتة، فانيليا (سنجل ودبل).
* **القهوة التراثية والأصيلة:** القهوة العربية بالزعفران والهيل، قهوة الجَبَنَة السودانية بالفخار والزنجبيل، والتركي المختص سنجل أوريجين.
* **المشروبات الدافئة الشتوية:** هوت شوكليت بلجيكي فاخر، هوت بطاطا بالكراميل، هوت لوتس، هوت بيستاشيو، شاي كرك أصيل، شاي عدني، وشاي ماسالا هندي.
* **المميزات:** جدول معايير درجات السكر المعتمدة لعماد أفندي (سادة، حبانوه، مظبوط، مانو، زيادة).

### 3️⃣ محطة الباك بار والحلويات السريعة (`/stations/backbar/`)
* **الفرابيه الكريمي:** فرابيه كوفي، شيكولاتة، فانيليا، موكا، وتوفي كوفي كرانش.
* **الميلك شيك الثقيل:** أوريو، لوتس، كيندر بوينو، رافايلو، نوتيلا، فيريرو روشيه، بيستاشيو، ميكس بيري دايجستف، و12 صنف فواكه طبيعية.
* **السموذي المنعش (19 صنف):** مانجو فريش، ليمون نعناع مصفى، بلوبيري، ميكس بيري، باشن فروت، بطيخ، جوافة، تفاح أخضر، كركديه...
* **الموكتيل والبوبا فيز الفوارة:** بوبا فيز (بلوبيري، فراولة، مانجو، باشن، ليتشي)، موخيتو ليمون نعناع، بلو باشن، وشيري كولا.
* **محطة الوافل والبان كيك:** معايير العجينة، درجات حرارة الماكينات (185°C - 190°C)، توقيت التسوية بالثانية، وأوزان التوبينج (40g).

## 💎 المميزات الاستثنائية للنظام

1. **⚡ وضع ضغط الشغل (Rush-Hour Mode):**
   زر أعلى الشاشة بضغطة واحدة يُخفي النصوص الطويلة ويعرض فقط الأرقام الكبيرة بوضوح فائق (الجرامات، المللي، عدد البمبات، الحرارة) لسرعة القراءة في ثانية واحدة أثناء زحمة الشفت.
2. **🚨 عيادة إنقاذ الأوردر ومكافحة الهدر (Zero-Waste Rescue):**
   حلول فورية موثقة لكل مشروب إذا حدث خطأ (استخلاص سريع، فوم زائد، التصاق الوافل، ثقل القوام) لإعادة تدويره وإنقاذه دون رميه وتكليف الكافيه.
3. **🧹 شيك ليست النظافة التفاعلية (Station Checklist):**
   قوائم تنظيف يومية وأسبوعية لكل محطة مع حفظ تلقائي محلي (LocalStorage) لعلامات الفحص.
4. **🖨️ مولد أكواد QR عالي الدقة (300 DPI):**
   توليد تلقائي لبطاقات طباعة فاخرة بهوية عماد أفندي الملكية (أسود وذهبي) جاهزة للطباعة على ستاندات أكريليك أو فينيل عازل للحرارة والرطوبة.

## 🛠️ التشغيل والتعديل

### تشغيل النظام محلياً:
يمكنك فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل سيرفر محلي خفيف:
```bash
python -m http.server 8080
```
ثم فتح: `http://localhost:8080`

### إعادة توليد بطاقات الـ QR برابط مخصص:
```bash
python generate_qrcodes.py "https://your-domain.com/"
```
